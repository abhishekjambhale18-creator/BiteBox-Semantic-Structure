### 📌 Project Overview
This lab focuses on upgrading the BiteBox website by implementing **semantic HTML5 tags**.  
Instead of using only basic tags, the page is now structured using `header`, `nav`, `main`, `section`, `article`, `aside`, and `footer` for better meaning and organization.

---

### ✨ What Was Improved
- Added `<header>` for branding and navigation
- Used `<nav>` for page links
- Wrapped main content inside `<main>`
- Used `<section>` for logical content blocks
- Used `<article>` for featured dishes
- Used `<aside>` for customer notice
- Added proper `<footer>` for copyright
